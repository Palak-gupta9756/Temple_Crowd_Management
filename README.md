# 🛕 Temple Crowd Management System

> **An AI-powered digital platform for smart, safe, and efficient management of temple and pilgrimage crowds.**

The **Temple and Pilgrimage Crowd Management System** is a smart web-based platform designed to improve the safety, convenience, and overall experience of devotees visiting high-footfall pilgrimage destinations.

The system combines the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** with **Artificial Intelligence, real-time crowd monitoring, predictive analytics, digital darshan booking, QR-based passes, alerts, and centralized administration**.

The platform focuses on four major pilgrimage destinations:

* 🛕 **Somnath Temple**
* 🛕 **Dwarka**
* 🛕 **Ambaji Temple**
* 🛕 **Pavagadh Temple**

The goal is to transform traditional pilgrimage management into a **smart, technology-driven, scalable, and safer digital experience** for both devotees and temple authorities.

---

# 🌟 Project Overview

India has numerous temples and pilgrimage destinations that attract millions of devotees throughout the year. During festivals, weekends, and auspicious occasions, these locations can experience significant increases in footfall.

Traditional crowd management methods can result in:

* Long queues
* Increased waiting times
* Crowd congestion
* Difficulty in monitoring crowd density
* Delayed emergency response
* Resource allocation challenges
* Difficulty planning visits during peak hours

This project addresses these challenges through a centralized digital platform that allows devotees to **plan their visits, book darshan slots, monitor crowd conditions, access temple services, and receive important notifications**, while allowing authorities to **monitor crowds, manage operations, allocate resources, and respond to emergencies**.

The system is designed around two primary interfaces:

### 👤 Devotee Panel

A user-facing platform where devotees can manage their pilgrimage journey.

### 🛡️ Admin Panel

A centralized management dashboard for temple authorities and administrators.

---

# 🎯 Problem Statement

Large-scale pilgrimages require continuous monitoring and coordination of:

* Crowd movement
* Darshan queues
* Entry and exit points
* Parking
* Emergency situations
* Medical assistance
* Accessibility services
* Nearby facilities
* Staff deployment
* Visitor information

Without a centralized digital system, it becomes difficult to provide real-time information to devotees and make fast, data-driven decisions.

The proposed system provides a centralized platform for **crowd monitoring, prediction, booking, alerts, temple services, and operational management**.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/Palak-gupta9756/Temple_Crowd_Management.git
```

```bash
cd Temple_Crowd_Management
```

---

## 2. Backend Setup

```bash
cd backend
npm install
```

Create your environment file:

```bash
.env
```

Add the required backend configuration such as your database connection and authentication/API credentials.

Then start the backend:

```bash
npm run dev
```

---

## 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

The development server will provide the local URL in the terminal.
